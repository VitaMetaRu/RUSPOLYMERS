# НОВАТЭК-ПОЛИМЕР

## WordPress сайт производителя полиэтиленовых пакетов и плёнки

### Описание
Сайт компании НОВАТЭК-ПОЛИМЕР - производителя высококачественных полиэтиленовых пакетов и плёнки.

### Требования
- WordPress 6.0+
- PHP 8.0+
- MySQL 5.7+

### Установка
1. Клонировать репозиторий
2. Разместить файлы в корневой директории WordPress
3. Активировать тему NOVATEK-POLYMER
4. Импортировать контент из файла `content.xml`

### Структура сайта
- Главная страница с баннером и преимуществами
- Каталог продукции (6 основных категорий)
- Страница производства
- Страница контактов с формой обратной связи
- Форма заказа звонка

### Технологии
- HTML5
- CSS3
- Bootstrap 5
- jQuery
- WordPress REST API
